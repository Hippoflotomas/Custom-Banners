## Version 1.1.3
Fallback "Missing" banner is now built into the dll, so it always installs to the right place.
Banner file names (Banner.json, Icon.png, MainTex.png, etc.) are no longer case sensitive.
Updated to Jotunn 2.30.2.
Fixed banners based on the Dvergr curtains and hanging doors: the image now covers every cloth piece (back faces, worn and broken states), and destruction pieces keep the vanilla look.
Bump maps now light correctly on custom images.
Log warns when MainTex.png is the wrong shape for its base banner.
Missing banner notice now works: a centre-screen alert once you're in the world, plus one chat line per missing banner.
Placeholder swap no longer changes the banner in the saved world.
